# BusBook

## Project Description
BusBook is a native Android bus booking management application. It helps users search available buses, view seat layouts, select seats, and manage their bookings.

## Problem Statement
Passengers may find it difficult to organize bus searches and booking details in one place. BusBook aims to provide a simple interface for managing these tasks.

## Main Features
- Search buses by departure and destination cities.
- View sample bus information.
- View a seat layout and select seats.
- Create and view bookings.
- Update or cancel bookings.
- Receive local booking reminders.

## Technology Stack
- **Platform:** Native Android
- **Programming Language:** Java
- **IDE:** Android Studio
- **Database:** SQLite
- **Version Control:** Git and GitHub

## Project Scope
BusBook is an academic project. It will use sample bus data and local booking records. It will not process real payments or provide live bus reservations.

## How to Run
1. Install Android Studio.
2. Clone or download this repository.
3. Open the project in Android Studio.
4. Allow Gradle Sync to complete.
5. Connect an Android phone with USB debugging enabled.
6. Select the device and click Run.
